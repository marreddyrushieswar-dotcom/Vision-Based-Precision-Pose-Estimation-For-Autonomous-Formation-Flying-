# Vision-Based Pose Estimation for Autonomous Formation Flying
### Machine Learning Mini-Project | ANN + Particle Filter

This project re-implements **“Vision-Based Precision Pose Estimation for Autonomous Formation Flying”** by R. Punnoose (Stanford) for the UE24CS352A Machine Learning mini-project.

A follower aircraft estimates the relative pose of a leader using 14 detected structural features generated by a simulated CNN detector.

## How It Works
1. **ANN Classifier:** Uses 42 input features and predicts a pose label through a 100–100 hidden-layer network with ReLU and softmax.
2. **Particle Filter:** Estimates the 6-DoF relative state using aircraft dynamics, feature-based likelihoods, and ANN-informed particle proposals.
3. **Project Extensions:** Adds Gaussian likelihoods, Levenberg–Marquardt reprojection refinement, a known line-of-sight option (`--known-los`), softmax-mean ANN estimates, and a softmax particle proposal.

> **Dataset:** The paper does not provide a public dataset. Training and validation data are generated synthetically with `data_gen.py`.

## Setup
Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Run the Project
Run the scripts in the following order:

```bash
python data_gen.py --n-train 600000 --n-val 40000
python train_ann.py --epochs 20
python simulate.py
python simulate.py --likelihood gauss --refine
python simulate.py --likelihood gauss --refine --known-los
python simulate.py --likelihood gauss --proposal softmax
python simulate.py --likelihood gauss --proposal softmax --sigma-px 1 --known-los
python summarize.py
python compare_paper.py
python visualize.py
```

The paper's curves for comparison are stored in `paper_data/`. Training can take 15–70 minutes on a CPU with the default settings. For a quicker test, use `--n-train 100000 --epochs 10`.

The trained model files (`models/ann.npz` and `models/error_pool.npy`) are included, so the demo can be run directly with:

```bash
python simulate.py --seeds 1
```

## Results

### Paper vs. Project
![paper vs ours](Autonomous-Formation-Flying-master/results/paper_vs_ours_summary.png)

The reference curves were digitised from Figures 9 and 10 of the paper. The paper reports mean position errors of 10.2 m (N=1000) and 8.5 m (N=5000). The attitude metrics are not directly equivalent because this project measures the full 3-D rotation angle, including leader pitch and yaw.

### ANN and Particle Filter Performance
- **ANN validation:** 33.6% top-1 accuracy and 81.1% top-5 accuracy.
- **Position RMS:** Improves from 8.25 m using the arg-max bin centre to 6.10 m using the softmax mean.
- **Best reported configuration:** Gaussian likelihood with softmax proposal and known line of sight achieves **0.32 ± 0.07 m** position error and **1.43°** attitude error.
- **Refinement:** Levenberg–Marquardt refinement with known line of sight reaches approximately **0.31 m** position error and **0.26°** attitude error.

| Method (10-second approach) | No known LOS | Known LOS |
|---|---|---|
| ANN, arg-max bin | 6.02 m / 5.04° | 4.12 m / 5.04° |
| ANN, softmax mean | 3.09 m / 2.85° | 1.62 m / 2.85° |
| Particle filter, inverse-MSE likelihood (N=5000) | 3.87 ± 1.42 m / 3.65° | — |
| Particle filter, Gaussian likelihood (N=5000) | 2.05 ± 0.54 m / 3.67° | 1.50 ± 0.18 m / 3.21° |
| Gaussian likelihood + softmax proposal (N=5000) | 2.07 ± 0.08 m / 3.51° | **0.32 ± 0.07 m / 1.43°** |
| Levenberg–Marquardt refinement | 2.54 m / 1.98° | **0.31 m / 0.26°** |

### Notes
- The leader's pitch and yaw vary by ±5° but are not included in the ANN label. Fixing them at 0° improves top-1 accuracy in a separate experiment.
- The softmax proposal reduces run-to-run position-error variation.
- Pose-only refinement is limited by bearing ambiguity. The `--known-los` option supplies the follower's gimbal line of sight to reduce this ambiguity.

## Conventions and Simplifications
- Pose is represented as `[x, y, z, phi, theta, psi]`; `(x, y, z) = r_F/L`. For example, `x = -90` means the follower is 90 m behind the leader.
- The camera is gimballed at the leader, with a 1000 px focal length, 1280 × 960 image, and 0.5 px detector noise.
- Features may be missing when they are occluded or outside the image.
- Pitch-to-vertical and roll-to-lateral velocity relationships use `V_NOM * sin(angle)`, an interpretation of the paper's brief dynamics description.
- Particle injection uses an empirical pose-error distribution computed from the validation set.
